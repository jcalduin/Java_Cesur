# Aprendiendo Java

Repositorio de practica y estudio de Java, organizado por temas del curso.

## Contenido por carpetas

- `00_Material extra/`: recursos y material complementario.
- `01_Iniciacion Java. Tema1/`: fundamentos del lenguaje (variables, tipos, operadores, estructuras de control).
- `02_Ejercicios Iniciacion.Tema2/`: relaciones de ejercicios, practicas y examenes de iniciacion.
- `03_POO. tema3/`: programacion orientada a objetos basica.
- `04_POO.tema4/`: herencia, polimorfismo, sobreescritura y examenes practicos/teoricos.
- `05_Tipos enumerados y Arrays.Tema5/`: enums, arrays y practicas relacionadas.
- `06_Paquetes, stattic y final.Tema6/`: paquetes, `static`, `final` y ejercicios de examen.
- `07_Excepciones/`: manejo de excepciones y creacion de excepciones personalizadas.
- `08_Archivos e Introduccion a Swing/`: ficheros, flujos de E/S y primeras interfaces con Swing.
- `09_Clases Abstractas/`: practicas con clases abstractas.

## Tecnologias

- Java (consola y Swing en algunos ejercicios).
- Estructura de proyectos independientes por practica/tema.

## Como ejecutar un ejercicio

Cada carpeta suele contener ejercicios independientes. Puedes compilar y ejecutar desde terminal dentro de la carpeta del ejercicio.

```bash
javac NombreArchivo.java
java NombreClase
```

Si el ejercicio usa paquetes, compila/ejecuta respetando la estructura de paquetes.

## Objetivo del repositorio

Consolidar el aprendizaje progresivo de Java: desde conceptos basicos hasta POO, excepciones, archivos y bases de interfaces graficas.
